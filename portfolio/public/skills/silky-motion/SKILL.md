# 丝滑（silky motion）

目标：整条片看起来没剪过。上一个画面里的某个东西（按钮、点、线、胶囊、头像、一封邮件）不消失，换个身份成为下一个画面的主角或底色。不需要真的一镜到底，要的是每个转场都有东西「跨过去」。

来源：2026-11-08 对 @leomeethewoo（Intently）10 条产品片的逐帧拆解。他们 40 秒的片硬切 0–20 刀，画面却一直在动（帧差和普通 SaaS 片一样），转场全在镜头里完成。

和 `product-motion-film` 的关系：那个 skill 管流程（HTML + GSAP、`render(t)`、测试片、评审、渲染）；这个 skill 只管「镜头怎么接」。两个一起用。

## 写分镜时必须多填一列

分镜表每一行加一列 **「什么东西跨到下一镜」**，并写明用的是下面哪个机制。这一列填不出来的转场，就是硬切或淡入淡出，回去重想。

| 时间 | 画面 | 这一拍讲什么 | 跨到下一镜的元素 | 机制 |
| --- | --- | --- | --- | --- |

自检三问：
1. 全片有没有一个贯穿的元素（一个点、一封邮件、一枚 logo）在每场换身份？
2. 每个转场，观众的眼睛是不是被同一个东西带过去的？
3. 有没有任何一秒画面完全静止？（除了片尾 logo 的 1–2 秒）

## 六条语法

1. **一个元素穿过整条片。** 点、线、胶囊、头像在每个场景里换身份，用它连镜头，代替剪辑。
2. **组件单独演。** 不放整屏截图。一次只演一个 UI 组件，放大 3–4 倍摆在空白画布上，演完缩回它在界面里的位置。
3. **流程画成路径。** 发送、路由、分发都画成一个点沿线移动，沿途标出状态节点。
4. **句子里嵌实物。** 图标、胶囊、卡片直接排在一行字里，当一个词用。
5. **画面从不完全静止。** 停留期间保持 5–10% 的 scale 漂移（ease none）。
6. **字小、居中、一次只说一件事。** 一个品牌色加黑或白底；数字一律滚动。

## 机制库（HTML / CSS / GSAP）

| # | 机制 | 做法 | 跨镜头的是 |
| --- | --- | --- | --- |
| M1 | 按钮 → 点 → 画线 | 按钮文字用 `clip-path: inset(0 100% 0 0)` 或 `font-size:0` 收掉 0.2 s；本体 `width/height → 圆`，0.25–0.3 s，power3.inOut，可加一圈 bloom；点作为笔头，`stroke-dashoffset` 画出路径 1.6–2 s；下一场 UI 里有同形状的线 | 这个点 / 这根线 |
| M2 | 容器放大铺满 = 转场 | 胶囊、按钮或 logo 点 `scale` 放大到盖住视口，0.3–0.55 s，expo.in；放满那一刻下一场直接用这个颜色做底，新内容从 scale 1.15–1.3 收到 1，expo.out | 颜色 |
| M3 | 组件单独演，再缩回原位 | 空画布上只放一个组件，入场 back.out(1.4) 0.4 s；演完用 Flip 或手算位移飞到它在界面里的位置，界面同时淡入，0.6 s，expo.inOut | 组件本身 |
| M4 | odometer 数字 + 自适应胶囊 | 每位数一列 0–9 竖排，`overflow:hidden`，滚动 0.8–1.2 s expo.out；外面胶囊宽度跟着位数变 | — |
| M5 | 句子里嵌实物 | inline-flex 的一行字里放 token；词逐个出（y 20 → 0，0.35 s，stagger 0.12 s）；token 可以是上一场留下来的东西 | token |
| M6 | 一词一屏 + 漂移 | 每个词停 0.5–0.8 s，停留时 scale 1 → 1.15；强调时 punch-in 到局部 | — |
| M7 | 点沿路径走 + 状态节点 | SVG 路径上一个点走 2–3 s，power1.inOut；在 0.3 / 0.6 / 0.9 进度处淡入状态标签；镜头跟着点平移；到终点时点放大成卡片，或接 M2 | 这个点 |
| M8 | 分叉线列清单 | 从一个节点拉线，到分叉点分成 N 条，stagger 0.08 s 画出，每条末端一个标签；容器同时平移再拉远。讲路由、分发、痛点清单都合适 | 起点节点 |
| M9 | 白块揭字 | 标签先出白色实心块（scaleX 0 → 1，0.18 s），再从另一侧收掉露出文字；换字时同样先盖再揭 | — |
| M10 | 品牌形状做 wipe | 用品牌图形（竖条阶梯、圆）铺满再退场，露出 logo | 品牌形状 |

通用参数：入场 expo.out 或 power3.out，0.3–0.6 s；转场 expo.in 加速出画，约 0.3 s。一条 30–40 s 的片大约 8–12 个动作，用 M1、M2、M7 串起来。

## 踩过的坑

- 飞行元素的位置每帧用 `getBoundingClientRect` 现算，不要在加载时量（字体没加载完会偏）。
- 绝对定位的容器要写 `left:0; top:0`，否则它的静态位置可能在画面外，里面的飞行元素全看不见。
- 两个动效不要控制同一个元素的 opacity，后写的会盖掉先写的。时间不重叠也要分开用不同的元素。
- 元素缩成点时，如果它里面是文本节点，用 `font-size:0` + `gap:0` + `justify-content:center` 收文字，图标会自己居中。

## 不要抄的

- 3D 金属币雨、光面 3D 板子、光刃、卡片 rolodex：通用装饰，和功能无关，记不住是哪个品牌。
- sunburst 放射背景加飞出来的钞票、跑车：博彩调性。
- BREAKING NEWS 加新闻截图荧光笔：用烂了，还有版权和背书问题。
- 超粗窄体大字整条片硬切：只适合限时活动。
- 字面比喻（「easier」配一根羽毛）。
- 为了丝滑牺牲清楚。功能片先保证一看就懂，每个转场带过去的元素要和内容有关，不要为了连而连。
